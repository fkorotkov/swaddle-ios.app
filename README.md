# Swaddle website

Public marketing, support, and privacy pages for [Swaddle](https://swaddle-ios.app), a free baby care journal for iPhone.

Only the website is published here. Screenshots use fictional sample data.

Run `python3 scripts/verify_website.py` to check the site. Preview with `python3 -m http.server 8769 --directory website`. GitHub Actions publishes only `website/` to GitHub Pages.
